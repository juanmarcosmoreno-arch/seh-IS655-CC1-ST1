# 08 — ST2187 comparative genomics

Identification of ST2187 genomes, MLST verification, and rlmH-cstA interval comparison.

| Script | Purpose |
|--------|---------|
| `01_build_locus_state_matrix.py` | Presence/absence matrix for ST1 and ST2187 loci |
| `02_compare_anchor_intervals.py` | Compare rlmH-cstA intervals between ST1 and ST2187 |
| `03_formalize_comparison.py` | Nucleotide identity at multiple regions (core, module, flanking) |
| `04_map_breakpoints.py` | Map recombination breakpoints in cepa_18 mosaic genome |
| `05_characterize_ancestral_block.py` | Characterize ancestral defense-island block in ST2187 |
| `06_expanded_ST2187_search.py` | Expanded search: Souza 2023, Naushad 2020, Maine 2022 |

24 verified ST2187 genomes: see results/summary_tables/ST2187_expanded_search.tsv
